2. Mô tả

Trang web Portfolio cá nhân được xây dựng theo phong cách Gloss Black kết hợp Neon & Cyber Gaming UI. Dự án thể hiện thông tin giới thiệu bản thân, kỹ năng lập trình và danh sách các dự án tiêu biểu của một Frontend Developer, kết hợp các hiệu ứng tương tác trực quan, hiện đại và hỗ trợ chuyển đổi đa sắc màu (Multi-Theme).

3. Chức năng

Giới thiệu bản thân (Hero Section): Hiển thị tiêu đề, chức danh với hiệu ứng gõ chữ tự động (Typewriter), mô tả ngắn gọn và các số liệu thống kê nhanh.

Hệ thống chuyển đổi Theme: Cho phép người dùng chuyển đổi linh hoạt qua lại giữa 3 tông màu chủ đạo (Neon·Cyber, Aincrad·SAO, Jett·Radiant) ngay trên thanh header.

Hiệu ứng tương tác Canvas: Lưới laser và các hạt năng lượng tự động chuyển động và kết nối theo vị trí con trỏ chuột.

Kỹ năng (Tech Stack): Liệt kê các công nghệ (HTML5, CSS3, JavaScript, Git, Figma) kèm theo thanh mức độ năng lực (Level Bar).

Dự án tiêu biểu (Projects Showcase): Trưng bày các dự án (Javalorant, Ứng dụng HTLMHT, C++SGO, Game Chết) dưới dạng thẻ 3D Hologram có hiệu ứng hover mượt mà.

Form liên hệ tương tác: Giao diện gửi lời nhắn kết hợp cùng thanh mạng xã hội cá nhân trực quan.

4. Công nghệ

Ngôn ngữ nền tảng: HTML5 (Semantic Markup), CSS3 (Flexbox & Grid Layout), JavaScript (ES6+).

Thư viện & Tiện ích:

FontAwesome 6.4.0 (Icons giao diện)

Google Fonts (Space Grotesk, Plus Jakarta Sans, JetBrains Mono)

Thiết kế: Mobile-First Responsive, Glassmorphism & Neon Glow UI.

5. Yêu cầu môi trường

Để chạy và phát triển dự án này trên máy tính cá nhân, bạn cần chuẩn bị:

Trình duyệt web hiện đại: Google Chrome, Microsoft Edge, Firefox hoặc Safari (có hỗ trợ JavaScript và HTML5 Canvas).

Công cụ lập trình (Code Editor): Khuyên dùng Visual Studio Code (VS Code).

Tiện ích mở rộng (Extension): Cài đặt thêm extension Live Server trên VS Code để hỗ trợ chạy local server.

6. Cài đặt

Tải mã nguồn về máy:
Clone repository từ GitHub hoặc tải file nén .zip của dự án về máy tính rồi giải nén.

Mở thư mục trong VS Code:
Mở phần mềm VS Code, chọn File > Open Folder và trỏ tới thư mục chứa dự án (KT20A2.1).

Kiểm tra cấu trúc thư mục:
Đảm bảo cây thư mục của dự án có cấu trúc đúng chuẩn:

└── assets/

7. Cấu hình

Dự án sử dụng thuần HTML/CSS/JS tĩnh nên không yêu cầu cấu hình phức tạp qua file môi trường (.env). Tuy nhiên, bạn có thể tùy chỉnh trực tiếp:

Biến màu sắc (:root): Thay đổi mã màu hex trong thẻ <style> của file index.html nếu muốn tùy biến lại bảng màu.

Đường dẫn tài nguyên: Đảm bảo các file hình ảnh trong thư mục assets/img/ trùng khớp tên với các thuộc tính src trong code HTML.

8. Chạy thử

Mở file index.html trong phần mềm VS Code.

Nhấp chuột phải vào vùng trống trong file index.html và chọn Open with Live Server.

Trình duyệt web mặc định sẽ tự động mở trang web xem trước ở địa chỉ: http://127.0.0.1:5500/index.html.

Trải nghiệm các chức năng: Bấm nút đổi theme ở header, di chuyển chuột để kích hoạt hiệu ứng hạt canvas và tương tác với các thẻ dự án.
